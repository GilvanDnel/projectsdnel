# Projectsdnel

## Tecnologias

- HTML
- CSS
- JavaScript

## Como visualizar

Abra `index.html` em um navegador.

## Estrutura

- `index.html`: pagina principal
- `style.css`: estilos
- `script.js`: interacoes
